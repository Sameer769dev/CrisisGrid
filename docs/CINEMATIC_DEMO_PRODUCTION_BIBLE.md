## 1. Visual Direction & Aesthetic Language

### A. Core Aesthetic: *Cyber-Tactical Neo-Brutalism*
- **Tone:** Urgent, authoritative, surgical, mathematically rigorous. Not a generic pastel SaaS demo.
- **Reference Films / Media:** *Sicario* (aerial thermal tracking), *The Martian* (NASA mission control telemetry), *Tenet* (precision reverse audio/pacing), and DARPA tactical defense displays.
- **Color Palette:**
  - **Void Black:** `#080B0E` (Deep tactical background)
  - **Hazard Crimson:** `#FF2B44` (Unverified proposals, flood hazards, blocked bridges)
  - **Verified Emerald:** `#00FFA3` (Mathematically proven corridors, cleared LZ, safe passage)

  - Headers / Badges: Heavy Monospace (`JetBrains Mono`, `Druk Wide`, or `Space Mono` Bold)

## 6. Video Editor "Secret Sauce" Polish Checklist

1. **2.39:1 Cinematic Letterbox Bars:** Place a subtle top/bottom letterbox mask (10% height) on B-roll cuts, but keep full 16:9 on the software UI so judges can read every number.
2. **Dynamic 3D Camera Punch-ins:** Whenever a button is clicked, punch in from 100% $\rightarrow$ 112% scale with a 15-frame bezier curve. It makes web app screencasts feel like a high-budget Apple keynote.
3. **Subtle CRT Scanlines:** Overlay a 1080p scanline PNG on the UI at `12% opacity` with blend mode set to `Overlay` or `Soft Light`. This gives the UI a military terminal command feel without hurting text legibility.
4. **Music Ducking:** Set up an automatic sidechain compressor on your music track triggered by the voiceover track. Whenever the voice speaks, the music drops -8 dB; during natural pauses, the music punches through.
